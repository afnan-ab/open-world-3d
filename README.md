# Open World 3D

High-fidelity browser-based 3D open-world exploration prototype built with Three.js.

**Not low-poly.** Features large procedural terrain, dynamic lighting, shadows, atmospheric fog, and smooth first-person controls.

## How to play

1. Open `index.html` in a modern browser (Chrome/Firefox/Edge recommended).
2. Click to lock pointer and start exploring.
3. WASD to move, mouse to look, Space to jump, Shift to sprint.

## Features

- Large seamless procedural terrain
- High-quality lighting and shadows
- Atmospheric perspective (fog)
- First-person character controller with physics
- Dynamic day-like lighting setup
- Performance-conscious rendering

## Tech

- Three.js (r170+)
- Pure HTML / CSS / JavaScript
- No build step required
